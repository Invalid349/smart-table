# Умная таблица

Интерактивная таблица для анализа данных продаж с фильтрацией, сортировкой, поиском и пагинацией. Проект использует DOM, обработку событий, модульную архитектуру и взаимодействие с сервером.

## Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/konovalov-nv/smart-table.git
cd ./smart-table
```
2. **Установите зависимости:**
```bash
npm install
```

3. **Запустите проект:**
```bash
npm run start
```

4. **Откройте браузер:**
```bash
http://localhost:4000
```

## Схема обработки данных
```bash
Исходные данные
       ↓
   Поиск (searching)
       ↓
 Фильтрация (filtering)
       ↓
  Сортировка (sorting)
       ↓
   Пагинация (pagination)
       ↓
  Вывод в таблицу (table)
```
